Classification Trigger Signal CLI Command Cost Model Engine Behavior
Quick check (yes/no) "is user logged in?", "is button visible?" skyvern browser validate 1 LLM + screenshots Lightweight validation (2 steps max), returns boolean. Cheapest AI option.
Quick inspection "what does the page show?" skyvern browser extract 1 LLM + screenshots Dedicated extraction LLM + JSON schema validation + response caching.
Single action (known) "click #submit-btn", "type email" skyvern browser click/type 0 LLM (Free) Deterministic Playwright execution. Sub-second speed, 0 tokens.
Single action (unknown) "click the save button" skyvern browser act 2-3 LLM (no screenshots) Uses economy accessibility tree (a11y). Suitable for semantic DOMs.
Same-page multi-step "fill the form and submit" skyvern browser act or primitive chain 2-3 LLM or 0 LLM Use act when labels are clear; use click/type chain when selectors known.
Throwaway trial "try this once", "see if it works" skyvern browser run-task Higher (autonomous loop) One-off autonomous agent for exploratory defect discovery.
Reusable automation "automate this weekly", "multi-page wizard" skyvern workflow create + run N LLM first run; 0 on replay Visual reasoning on run 1; caches deterministic script for subsequent runs.
  • Rule 1: If the prompt includes a selector, ID, XPath, or exact field target, use browser primitives (click, type) — never use act.
  • Rule 2: If you only need a yes/no answer, use validate — not extract or act.
  • Rule 3: If the work stays on one page and labels are clear, use act or a primitive chain.
  • Rule 4: If the user says "try this once", "see if this works", or wants a one-off exploratory trial, use run-task.
  • Rule 5: If the task spans multiple pages and is repeatable, use workflow create.
  • Rule 6 (Security Guardrail): NEVER type passwords directly. Always use stored credentials via skyvern credentials add and skyvern browser login.

Why did npm install -g skyvern fail?
Skyvern is an open-source Python (PyPI) package, not a Node.js/npm package. Running npm install -g skyvern returns npm error 404 Not Found because Skyvern does not publish to registry.npmjs.org.
Why did chrome.exe fail?
Google Chrome is verified installed at C:\Program Files\Google\Chrome\Application\chrome.exe, but this directory is not in Windows default system PATH. In PowerShell, you must invoke it with quotes or via the call operator &.

1. Launch Chrome with Remote Debugging (Port 9222)
