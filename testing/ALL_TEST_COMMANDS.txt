================================================================================
                    SDTRACKER MASTER TESTING COMMANDS GUIDE
================================================================================

This document provides the exact terminal commands to run all test suites either
together in a single command, or individually by category.

--------------------------------------------------------------------------------
1. MASTER COMMAND: RUN ALL TESTS AT ONCE (ONE-CLICK)
--------------------------------------------------------------------------------

Command (via npm):
  npm run test:all

Command (via npx / tsx directly):
  npx tsx testing/RUN_ALL_TESTS.ts

What it does:
  Executes all 5 test suites sequentially:
    1. TypeScript Typecheck & Static Analysis
    2. Unit Test Suite (Schema adapters, envelope packing, data migration)
    3. PostgreSQL 29-Table & 31-Page Live Storage Coverage Audit
    4. Automated QA System Diagnostics & HTML Report Generator
    5. User Acceptance Testing (UAT) Master End-to-End Suite
  Prints an executive summary table and updates all dated report files.


--------------------------------------------------------------------------------
2. INDIVIDUAL TEST COMMANDS BY TEST TYPE
--------------------------------------------------------------------------------

[SUITE 1] USER ACCEPTANCE TESTING (UAT)
---------------------------------------
Command:
  npm run test:uat
  OR
  npx tsx testing/02_TEST_SUITES/uat/uat-master-suite.ts

What it tests:
  - Full end-to-end user journeys across 22 functional areas (15 master scenarios)
  - Super Admin, Admin, Site Manager, Welfare Officer, and Night Shift personas
  - Verification of all 8 QA defects:
      * QA-01: Dynamic columns dual-layer persistence (localStorage + DB)
      * QA-02: Laundry Support record creation for Site Manager role
      * QA-03: Hot Meals Tracker initial buffet headcount persistence
      * QA-04: Hot Meals Tracker 4-vendor matrix default rendering
      * QA-05: SD VCS Directory master partner agency data display (69 agencies)
      * QA-06: PDF export adaptive layout & font scaling on wide tables
      * QA-07: High-frequency update latency benchmark (<50ms)
      * QA-08: Booklet Inventory consignment creation, discovery, & highlight
Output Files:
  - Live Web:  http://localhost:3020/uat-results.html
  - HTML:      testing/03_RESULTS_AND_REPORTS/UAT_RESULTS_LATEST.html
  - JSON:      testing/03_RESULTS_AND_REPORTS/UAT_RESULTS_LATEST.json
  - Markdown:  testing/03_RESULTS_AND_REPORTS/UAT_RESULTS_2026-09-13_SUMMARY.md


[SUITE 2] UNIT TESTS (DATA ENVELOPES & MIGRATION)
-------------------------------------------------
Command:
  npm run test:unit
  OR
  npx tsx --test server/schemaAdapter.test.ts src/services/legacyLocalDataMigration.test.ts

What it tests:
  - 49 automated unit tests verifying schema adapter bidirectional conversion
  - JSONB data envelope packing on mutation writes
  - Dynamic column persistence across all 20 data tables
  - LocalStorage legacy data migration and reconciliation with remote database
  - Strict date boundary validation and RBAC notification filtering


[SUITE 3] DATABASE RELATIONAL SCHEMA & STORAGE COVERAGE
-------------------------------------------------------
Command:
  npm run db:coverage
  OR
  npx tsx scripts/verify-db-coverage.ts

What it tests:
  - Live REST reachability of all 29 PostgreSQL database tables
  - Confirmation that all 31 operational frontend pages are backed by live DB
  - Schema integrity checks across primary keys, foreign keys, and JSONB envelopes


[SUITE 4] QA SYSTEM DIAGNOSTICS & DATED REPORT
----------------------------------------------
Command:
  npm run test:qa:report
  OR
  npx tsx scripts/generate-qa-report.ts

What it tests:
  - Compiles live diagnostics, test metrics, and database coverage
  - Generates dated standalone HTML report for executive and compliance review
Output Files:
  - HTML:  testing/03_RESULTS_AND_REPORTS/QA_SYSTEM_REPORT_LATEST.html
  - Dated: testing/03_RESULTS_AND_REPORTS/QA_SYSTEM_REPORT_2026-09-13.html


[SUITE 5] TYPESCRIPT STATIC ANALYSIS & TYPE SAFETY
--------------------------------------------------
Command:
  npm run lint
  OR
  npx tsc --noEmit

What it tests:
  - Zero compile errors across all 2,400+ TypeScript modules and components
  - Strict interface contract adherence between backend routes and frontend UI


[SUITE 6] PRODUCTION BUNDLE BUILD CHECK
---------------------------------------
Command:
  npm run build

What it tests:
  - Compiles Vite client production bundle into dist/
  - Bundles Express backend server with esbuild into dist/server.cjs
